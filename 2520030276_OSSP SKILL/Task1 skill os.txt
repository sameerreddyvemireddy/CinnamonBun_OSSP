## OSSP TAsk 1 - Step-by-Step (macOS)
Part 1: C Program using fork(), exec(), and wait()
Step 1: Open Terminal
Press ⌘ + Space, type Terminal, and press Enter.

Step 2: Go to the Desktop
cd ~/Desktop

Check your current location:
pwd
Observation:/Users/your_username/Desktop
Step 3: Create a C file
nano forkexec.c
Paste the following code:
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main()
{
    char command[100];

    printf("Enter Linux command: ");
    scanf("%s", command);

    pid_t pid = fork();

    if(pid < 0)
    {
        printf("Fork failed\n");
        return 1;
    }
    else if(pid == 0)
    {
        printf("\nChild Process\n");
        printf("Child PID : %d\n", getpid());

        execlp(command, command, NULL);

        printf("Command execution failed\n");
    }
    else
    {
        printf("\nParent Process\n");
        printf("Parent PID : %d\n", getpid());

        wait(NULL);

        printf("Child process completed.\n");
    }

    return 0;
}

Step 4: Save the file
Ctrl + O
Enter
Ctrl + X
Step 5: Compile the program
gcc forkexec.c -o forkexec
Observation
If there are no errors, nothing is displayed.
Step 6: Run the program
./forkexec
When prompted:
Enter Linux command:
ls
Example Output:

Child Process
Child PID : 52929

Desktop
Documents
Downloads

Child process completed.
